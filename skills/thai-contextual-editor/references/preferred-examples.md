# ตัวอย่างภาษาไทยที่ต้องการ

ไฟล์นี้เป็นแหล่งอ้างอิงสำหรับสำนวนและน้ำเสียงที่ผู้ใช้ยอมรับแล้ว ให้ใช้เป็นแนวทาง
ไม่ใช่กฎแทนบริบท และเพิ่มตัวอย่างใหม่เมื่อผู้ใช้ยืนยันว่าต้องการเก็บเป็นมาตรฐานเท่านั้น

## หลักทั่วไป

- เขียนให้ตรง ชัด และเป็นธรรมชาติ ไม่เติมคำสุภาพหรือภาษาทางการโดยไม่จำเป็น
- รักษาน้ำเสียงของผู้พูด อย่าทำให้ทุกคนมีเสียงเดียวกัน
- ใช้คำทับศัพท์ที่คนในสาขาใช้จริง แทนการฝืนบัญญัติศัพท์ที่ทำให้เข้าใจยาก
- คงคำอังกฤษหรือใช้ไทยปนอังกฤษเมื่อเป็นวิธีที่คนไทยใช้จริงและช่วยให้อ่านเข้าใจง่ายกว่า
  อย่าฝืนแปลทุกคำเป็นภาษาไทยจนข้อความฟังไม่เป็นธรรมชาติ
- ตัดคำฟุ่มเฟือยเมื่อไม่ทำให้ความหมายหาย แต่ไม่ลบรายละเอียดสำคัญเพื่อให้ประโยคสั้น

## Preferred / Avoid

| บริบท | หลีกเลี่ยง | ใช้เมื่อเหมาะกับบริบท |
|---|---|---|
| UI | กรุณาทำการคลิกปุ่ม | กดปุ่ม |
| สถานะงาน | การดำเนินการเสร็จสมบูรณ์แล้ว | ดำเนินการเสร็จแล้ว |
| ซัพพอร์ต | ทางเราได้รับทราบถึงปัญหาแล้ว | เราได้รับแจ้งปัญหาแล้ว |
| การเปิดตัว | เรารู้สึกตื่นเต้นที่จะประกาศ | วันนี้เราเปิดตัว / ขอแนะนำ |
| เทคนิค | ทำการรีสตาร์ทเซิร์ฟเวอร์ | รีสตาร์ทเซิร์ฟเวอร์ |

คำในคอลัมน์ “หลีกเลี่ยง” ไม่ใช่คำต้องห้าม หากบริบททางกฎหมาย พิธีการ หรือเสียงของผู้พูด
ต้องใช้ถ้อยคำนั้น ให้รักษาบริบทไว้ก่อน
